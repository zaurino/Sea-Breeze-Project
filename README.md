# Sea Breeze в Европе — Заур Фархадов

Интерактивная веб-презентация предложения о развитии европейского направления Sea Breeze.

## Запуск

Сайт статический: сборка и установка зависимостей не нужны.

```bash
python3 -m http.server 8080 --directory dist
```

Откройте http://localhost:8080 в браузере. Для публикации загрузите содержимое `dist` на любой хостинг статических сайтов.

## Структура

- `dist/index.html` — содержание, интерактивная карта и контакты.
- `dist/luxe.css` — адаптивный дизайн и анимации.
- `dist/luxe.js` — управление видео, городами, модальными окнами и шапкой.
- `dist/assets/` — видео, фотографии, шрифты и визуализация офиса.

## Поведение

Шапка с эффектом стекла появляется после вступительного видео или при переходе к следующим разделам. При выбранном Милане фото офиса видно сразу; нажатие увеличивает изображение. Номера в шапке и футере открывают WhatsApp. Instagram ведёт на профиль @farhadovzaur. Учитывается системная настройка уменьшения движения.

## Содержание

Фотография Заура и профессиональные сведения предоставлены заказчиком. Офисы Sea Breeze в Ницце и Милане — визуализации предложения, а не подтверждение действующих представительств. Географическая основа карты — Natural Earth (world-atlas 2.0.2).
